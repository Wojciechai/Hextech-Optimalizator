# ⚡ Hextech Optimalizer

**A Windows 11 optimization tool built with PowerShell 5.1 and WPF (.NET Framework).**

Hextech Optimalizer is a personal project focused on developing a graphical tool for Windows system optimization, performance management, and system configuration.

The project aims to make selected system maintenance and optimization tasks more accessible through a simple graphical interface.

> 🚧 **Status: Prototype / Active Development**
>
> This project is currently under development. Features, interface elements, and functionality may change over time.

---

## 🎯 Project Goals

- Simplify selected Windows optimization tasks.
- Provide an accessible graphical interface for system configuration.
- Explore PowerShell automation and Windows system management.
- Improve the user experience when performing system maintenance.
- Develop a modular and expandable optimization tool.
